# Personal site

A one-page resume for recruiters and tech leads; these terms describe how
visitors experience it.

## Appearance

**Theme**:
A named look the visitor can pick for the whole site: light, dark or
neobrutalism. A theme sets the colors and may also set its own style
(borders, shadows, type).
_Avoid_: skin, mode, color scheme

**Auto**:
The visitor's default choice, which follows the operating system's light/dark
preference. It is not a theme and never selects neobrutalism.
_Avoid_: system theme, default theme

**Neobrutalism**:
A dark-only theme with flat color blocks, thick solid borders, hard offset
shadows, square corners and monospace type throughout.
_Avoid_: brutalism, neo theme
